# Milestones: Put the Concepts Together

A milestone is a small project that combines several earlier lessons. These projects are not separate topics: they are practice grounds for input, variables, arithmetic, decisions, loops, and functions.

## Project 1: Tic-tac-toe

Open the [game lesson](game/game-README.md). The program needs to track the board, whose turn it is, whether a move is legal, and whether someone has won or the game is a draw. Read the source with those responsibilities in mind rather than trying to understand every line at once.

## Project 2: Console banking simulation

Open the [bank lesson](bank/bank-README.md). This project uses a menu to choose an operation, variables to track a balance, conditions to validate actions, and a history list to record activity. It is educational only and is not a real banking system.

## A method for reading a larger program

1. Find `main()` and see how the program starts.
2. Find the main data: what values must the program remember?
3. Find the loop that keeps the program running.
4. Find the decisions that choose which action happens.
5. Trace one complete user action from input to output.
6. Test an ordinary case, a boundary case, and invalid input.

## Project work

For each milestone, first run the program unchanged. Then select one improvement from its project README, make the change, and test it. Keep a short note of what changed and why. A useful project is one that can be explained, not just one that happens to run.
