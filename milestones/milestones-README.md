# milestones

Small projects that combine concepts from the existing tutorial folders. These are practice projects, not production applications.

| Subfolder | README | What it is |
|---|---|---|
| `game/` | [game-README.md](game/game-README.md) | Two iterations of a two-player console tic-tac-toe game. |
| `bank/` | [bank-README.md](bank/bank-README.md) | A console banking simulation practicing functions, conditions, loops, namespaces, and arrays. |

## Suggested order

Start with the game to practice arrays, functions, loops, and conditions. Then inspect the banking simulation to see menu-driven control flow, validation, and a fixed-size transaction history working together.
